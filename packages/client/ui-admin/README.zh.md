# @deepseek-ai/dsh-client-ui-admin

[English](README.md) | 中文

## 概述

此可选 Web 面板为当前服务所有者提供会话表格、可读聊天历史、工具调用详情，以及 DeepSeek 用量和成本估算。它通过经过身份验证的 Remote 方法读取[管理服务](../../session-query/admin/README.zh.md)。打开记录不会恢复运行其 Agent。

## 使用本包

将此 Client 插件与管理服务一起挂载。侧栏的管理后台入口打开会话表格；概览、工具调用和成本共用当前筛选。搜索、模型、状态以及包含首尾日期的北京日历范围用于筛选服务器查询。会话和工具调用初始显示全部日期；概览和成本初始覆盖最近七个北京日历日。明确应用或清空的筛选会在切换标签页时保留。打开会话后显示独立于列表筛选的历史，提供聊天、工具和用量标签页、父会话链接及分页后代会话链接。子会话统计需要明确勾选包含子会话选项。

表格按当前显示的筛选和索引版本导出 CSV。如果导出前索引或价格发生变化，页面会要求刷新，不会导出另一版本的数据。用量或价格缺失会明确显示为未知。价格配置接受 DeepSeek 的三类 Token 单价；历史补价需要单独明确选择。成本估算不代表供应商账单。

刷新失败时，页面保留最近成功读取的记录，并显示重试提示。索引进度和部分失败保持可见，重建索引按钮用于请求恢复。工具参数和结果仅在展开时加载。被截断的聊天消息可按需展开单条内容，仍受服务器详情上限限制；尚未完整显示时会继续标记截断。宽表格在页面内部滚动，长记录内容可选取并滚动查看。

| Client 配置 | 默认值 | 用途 |
|---|---:|---|
| `refreshIntervalMs` | `10000` | 页面持有查询资源时的刷新间隔 |
| `pageSize` | `50` | 每页行数，范围为 1 至 100 |
| `initialDays` | `7` | 概览和成本的初始北京日历日期范围 |

<a id="understand-the-implementation"></a>
## 实现说明

插件先挂载生成的管理 Remote 方法，再注册全局主面板和侧栏入口。查询记录由 Client Resources 管理；声明的视图 store 仅保留导航、筛选和分页状态。每个表格及其汇总读取同一已观察到的索引版本。页面释放会中止刷新计时器，正在进行的请求结束后也不会继续后续读取。

被动 Session follow 流观察已提交的会话活动，不会激活 Agent。超过索引水位的活动显示为等待索引，下一次资源刷新提供索引后的记录。插件卸载时，先移除 UI，再移除 Remote 方法。英文和中文词典一起注册，其他语言使用 locale 服务的英文回退。

<a id="model-experience"></a>
## 模型体验

无，因为管理界面读取已保存记录并配置估算单价，不添加模型工具、提示词或会话输入。

#### KV Cache 影响

无。查看和导出记录不会发送模型请求。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- 访问范围是当前服务所有者的记录，不提供多租户账户系统。
- 汇总跟随管理索引，尚未完成的工作不构成已结算用量记录。每日图表、日历筛选、时间显示和价格生效日期均使用北京时间（UTC+8）。
- 主面板选择和筛选是临时状态，没有独立的可收藏地址。
- 工具详情显示已记录内容，可能含有敏感值；会话用户文本遮罩插件不会清洗这些记录。
