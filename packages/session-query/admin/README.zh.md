# @deepseek-ai/dsh-admin

[English](README.md) | 中文

## 概述

此可选 Host 插件向实例所有者提供 `admin` Remote 命名空间。它索引本地会话和工具执行，根据记录用量及管理员配置的价格估算 DeepSeek 成本，并导出相同筛选范围的 CSV。它不收款，也不提供供应商账单。日志读取通过 prepared observation 完成，不启动冷会话的 agent。

## 使用本包

将此服务与 `sessionQuery`、`sessionProjections`、`sessions` 和 `sessionPersistence` 一同挂载。可选的[管理界面](../../client/ui-admin/README.zh.md)负责浏览器入口。每个 Remote 操作都会检查调用者是否为实例所有者，包括详情、价格、重建和导出；可信查询基础设施本身不提供此授权。

| 配置 | 含义 | 默认值 |
|---|---|---|
| `path` | 保存元数据和持久化价格版本的专用 SQLite 绝对路径 | 必填 |
| `refreshIntervalMs` | 后台核对会话集合的间隔 | `5000` |
| `pageSizeMax` | 交互分页的最大行数 | `100` |
| `detailBytesMax` | 序列化详情响应的最大字节数 | `65536` |
| `exportRowsMax` | CSV 最大行数 | `10000` |
| `exportBytesMax` | UTF-8 CSV 最大字节数 | `16777216` |

会话列表按最近活动排序，日期筛选使用创建时间。用量和工具的日期筛选使用调用开始时间。时间范围包含起点、不包含终点。文本筛选按字面匹配会话标题、工作目录或 id。模型、生命周期及可选的父会话和后代筛选作用于索引元数据。每日用量按 Asia/Shanghai 日期分组。概览会话数量按匹配模型调用所属会话去重，包含在所选日期范围之前创建的会话。

价格覆盖官方 `deepseek-official` 和 `deepseek-account` 路由。每个模型版本记录币种、生效时间及每百万 Token 的三项十进制费率：未缓存输入、缓存输入和输出。版本持续生效到该模型的下一版本。`addPrice` 接受未来时间；`repriceHistory` 显式添加历史版本。两者都不覆盖已有版本。估算遵循所选的不可变价格历史，不合并不同币种。

用量字段缺失、价格缺失或路由不受支持均单独报告，不按零计价。上下文压力估算不作为供应商用量。推理 Token 已包含在输出中。此三费率 DeepSeek 计算器不支持非零缓存写入用量。fork 继承的前缀不计入费用和工具数量；读取聊天正文时仍可显示继承的消息。

每页均标识其索引及价格修订。详情和 CSV 导出拒绝过期的所选修订，不混合不同观察；刷新页面后可以重试。导出包含修订与索引时间列，并将文本单元格中的电子表格公式转换为普通文本。导出过大时需缩小筛选范围。工具详情和原始事件内容有大小限制，并明确标记截断；事件分页可只选择可读的用户和助手消息，不重复携带原始载荷。单条事件查询可在配置的详情上限内展开被截断的消息。

`indexStatus` 显示就绪状态、进度和索引失败会话数。源数据失败时保留上次索引值并标明过期；修复源数据后重建。重建只清理派生表，保留价格版本。应在服务停止后或使用 SQLite 备份工具备份 `path` 指向的完整数据库；删除文件也会删除价格。不属于此服务的数据库和不支持的版本会被拒绝，不会被重置。

<a id="understand-the-implementation"></a>
## 理解实现

<details>
<summary>实现所有权</summary>

私有 Host Session projection 持有调用元数据和生命周期状态。索引器通过 `sessionQuery.observeState` 在精确的实时或 prepared observation 位置读取状态；普通客户端 Session 数据不包含管理台账。未变化的持久化修订和实时游标会跳过，已删除会话会被清理，每个会话的派生行通过事务发布。实时日志事件只调度后台工作，不等待数据库写入。卸载时停止调度、等待索引完成并关闭数据库。

投影为每次模型或工具调用保留一条元数据，因为分页审计查询需要这些身份信息；参数、结果和聊天正文保留在原日志。模型重试属于独立尝试。最终助手用量替换对应尝试的样本。摘要调用读取 `compaction/summary`；标题结算更新已记录的请求。嵌套 Code Mode 工具与外层调用分别标识，因此累计耗时不能解释为实际经过的时间。

</details>

价格版本可携带 `deepseekSchedule`，此时三项单价均为高峰价格：北京时间周一至周五 09:00–12:00、14:00–18:00，排除提供的节假日日期。其他时间均为半价，包括调休上班的周末。`validUntil` 限定已核验日历的有效范围，超出范围的调用显示价格缺失，直到配置新版本。按调用开始时间选择时段，普通输入、缓存输入与输出三个独立计数分别计费一次。价格与时段以[官方价格页](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)为准，调整时新增价格版本。

<a id="model-experience"></a>
## 模型体验

无，因为此服务读取已有记录，不增加模型提示词、工具 schema、模型调用或模型可见结果。

#### KV Cache 影响

无。索引和价格变化不修改模型请求或会话历史。

## 已知限制与待办工作

<a id="known-limitations-and-deferred-work"></a>

- 仅覆盖当前实例可读取的记录；外部供应商未记录的子调用和供应商账单不在索引范围内。
- 没有用量结算的历史标题请求、失败尝试缺失的用量、未产生摘要记录的失败压缩以及结算前进程退出均无法可靠计价。
- 冷观察会校验完整源日志。首次回填和未缓存的大会话详情读取可能较慢；普通列表只读取 SQLite 索引。
- 投影元数据和派生行随执行调用数增长。更新会替换一个会话的派生行；这是单实例内部管理后台，不是分布式分析服务。
- 每日汇总采用 Asia/Shanghai 日期。估算费用由十进制费率计算，不是支付台账，也不进行汇率换算。
