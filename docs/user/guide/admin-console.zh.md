# 查看会话与 DeepSeek 成本

[English](admin-console.md) | 中文

管理后台供实例管理员查看已记录的会话与工具、估算 DeepSeek 成本并导出统计。它读取当前实例可访问的会话，包括没有运行中 Agent 的历史会话。

## 从源码启用面板

安装依赖并构建源码后，通过管理后台覆盖配置启动 Web profile：

```sh
pnpm dsh web --patch apps/cli/config/examples/admin.overlay.yml --port 3081
```

打开启动时提供的登录链接，在侧栏选择**管理后台**。覆盖配置会同时启用管理服务和面板，在 Harness 主目录的 `admin/admin.sqlite` 中统一保存可重建的索引和持久化价格。数据库由一个进程拥有；不同实例应使用不同的 Harness 主目录。

## 查看会话

选择会话可查看聊天记录、工具调用和用量。读取历史不会恢复 Agent。被截断的聊天消息可在配置的详情上限内展开。展开工具可查看参数和结果；长输出有长度上限，截断时会明确标注。父会话和后代会话链接打开对应会话，子会话选项会将后代会话纳入当前工具与用量汇总，不重复计算继承的历史。

## 配置估算价格并导出

打开**成本**并展开 **DeepSeek 价格**。填写准确的模型标识、币种、生效时间，以及每百万未命中缓存输入、缓存命中输入和输出 Token 的价格。新价格用于未来调用。补充历史价格时，选择历史选项并明确执行重新估算；价格版本会保留。

已配置官方分时价格时，价格表显示高峰单价，并说明空闲半价规则与日历截止时间。按调用开始时的北京时间和已核验节假日日历计算，缺失的 Token 用量仍显示未知。Search 与 Fetch 的按次费用独立于此处的 Token 成本小计。

**导出 CSV** 使用当前显示的筛选条件和索引版本。若导出前记录发生变化，请刷新页面后重试。导出内容为统计数据，不包含聊天全文或工具原始结果，不同币种分别保留。

用量缺失和价格缺失会明确展示。成本小计仅覆盖具备所需用量计数及匹配价格的调用。没有记录用量的历史标题请求、未报告用量以及持久化结算前丢失的活动，无法还原为精确成本。其他供应商会被标记为不在 DeepSeek 计价范围内。这些估算不代表供应商账单。

## 恢复不完整的索引

面板会显示索引进度和失败状态。**重建索引**从 Session 日志重试，并保留已配置价格。索引失败不会停止 Agent 工作。重建仍无法读取会话或打开配置的数据库时，请查看服务端诊断。

部署上限与查询行为见[管理服务](../../../packages/session-query/admin/README.zh.md)和[面板参考](../../../packages/client/ui-admin/README.zh.md)。
